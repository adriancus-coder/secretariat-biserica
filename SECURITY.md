# Security policy

Please report vulnerabilities privately, through GitHub's **Security → Report a vulnerability** on this repository or by e-mail to secretariat@sanctuaryvoice.com — never in a public issue.

What to include, response times and how the app protects church data: [docs/SECURITY.md](docs/SECURITY.md#how-to-report-a-vulnerability). The technical design for reviewers: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

Only the latest version on the `main` branch (production) is supported.
